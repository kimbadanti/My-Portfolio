Medibot – Medical Chatbot using LLMs & RAG

Medibot is an intelligent medical assistant that leverages Retrieval-Augmented Generation (RAG) to provide context-aware responses to health-related queries. It uses LangChain and OpenAI's LLMs for dynamic conversation generation, Pinecone for semantic vector search, and Streamlit for an interactive frontend. The project demonstrates modular backend integration and scalable chatbot design using advanced NLP techniques.
