Chest Cancer Classification with MLOps Integration

The Chest Cancer Classification project is an end-to-end machine learning solution designed for classifying chest cancer images. It integrates data ingestion, preprocessing, model training, and MLOps tools like MLflow and DVC for experiment tracking and pipeline management. This project also includes automated CI/CD pipelines using Docker and GitHub Actions, with deployment on AWS EC2 and ECR. The Flask web application offers an intuitive interface for users to interact with the model and make predictions.

Medibot – Medical Chatbot using LLMs & RAG

Medibot is an intelligent medical assistant that leverages Retrieval-Augmented Generation (RAG) to provide context-aware responses to health-related queries. It uses LangChain and OpenAI's LLMs for dynamic conversation generation, Pinecone for semantic vector search, and Streamlit for an interactive frontend. The project demonstrates modular backend integration and scalable chatbot design using advanced NLP techniques.
